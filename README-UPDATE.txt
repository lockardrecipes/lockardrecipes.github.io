LOCKARD FAMILY — RECIPE VAULT update

Upload these three files to the ROOT of the GitHub repository, replacing the existing files:
- index.html
- styles.css
- app.js

Photo behavior:
- Recipe cards now use only the direct photo URL entered in each recipe's Photo link field.
- Automatic image scraping from recipe pages has been disabled because it can return unrelated thumbnails, logos, or badly cropped preview images.
- Photos are contained within the card image area rather than stretched or cropped. Use a direct image URL (usually ending in .jpg, .jpeg, .png, or .webp).

Favorite tags:
- The field is labeled Favorites.
- Existing stored tags such as Rachel, Mom, Dad, and Nathan are displayed as Rachel's favorite, Mom's favorite, Dad's favorite, and Nathan's favorite. Stored values are unchanged.
